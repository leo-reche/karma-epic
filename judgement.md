# Judgement

## The app

The Karma-LLMifier is a simple website that turns a video into a `.md` file. Users give the file to their own AI.

## My reasoning

- **Not a chatbot:** everyone already has an AI.
- **Knowledge:** the idea is to turn videos into knowledge.
- **Easy to use:** no Python knowledge is needed.
- **Start small:** first a quick Python proof of concept, then Google Cloud and a live internal website.
- **Next step:** a `SKILL.md` can help the user's AI learn how to implement it.
- **Pitch:** short white slides with my sketch, where points appear as I speak.
